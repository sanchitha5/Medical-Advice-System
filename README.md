# 🩺 Online Medicinal Advice System (Python)

This project is a **command-line based Python application** that provides basic medicinal advice based on common diseases.
The program greets the user according to the current time and allows them to select a disease to view its description and commonly used medicines.

⚠️ **Note:** This project is for **educational purposes only** and does not replace professional medical consultation.

---

## ✨ Features

* Personalized greeting based on current time (Morning, Afternoon, Evening, Night)
* User-friendly menu of 15 common diseases
* Disease description for better understanding
* Suggested commonly used medicines
* Simple and interactive command-line interface
* Beginner-friendly Python logic
